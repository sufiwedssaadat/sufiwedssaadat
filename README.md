# Royal Wedding Invitation Website

A responsive multi-page wedding invitation website inspired by the supplied card: midnight navy, antique gold, ivory, floral corners, lanterns, and Mughal arches.

## Run in VS Code
1. Extract `royal_wedding_website.zip`.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build tools, npm packages, or API keys are required.

## Change the dummy details
Edit `assets/data.js`. Names, date, time, venue, schedule, welcome text, quote, and family messages are centralized there and reused across the pages.

All names and event details currently shown are dummy data. Update them before publishing. The map button is a placeholder link; replace `mapUrl` with the real map link.

## Pages included
- `index.html` — cover / home
- `invitation.html` — formal invitation
- `blessings.html` — Quranic verse and welcome
- `programme.html` — event programme
- `venue.html` — venue details
- `couple.html` — couple page
- `family.html` — family greetings
- `dua.html` — special note and blessing
- `thank-you.html` — thank-you page

Static site hosting options include GitHub Pages, Netlify, and any ordinary web host.
